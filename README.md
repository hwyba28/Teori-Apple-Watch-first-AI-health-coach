# Teori — Apple Watch–first AI health coach

Teori turns your everyday Apple Watch data into short, personal coaching —
and checks its own predictions against how you actually felt.

AppStore_Link: https://apps.apple.com/us/app/teori-recovery-readiness/id6791511185

## Features
- Apple Watch–first experience with iPhone companion
- Daily check-ins that build a personal baseline over time
- Coaching grounded in your own data, not population averages

## Built with
Swift / SwiftUI · watchOS · HealthKit · Go backend · RAG-based coaching

Solo build in 50 days · released on the App Store (August 2026).
